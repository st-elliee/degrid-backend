# Degrid backend — οδηγίες χρήσης

Backend REST API με Node.js, Express και ES modules, σύμφωνα με το παραδομένο
OpenAPI **1.1.0, 26 λειτουργίες**. Όλα τα δεδομένα παραμένουν στη μνήμη.
Δεν απαιτούνται βάση δεδομένων, λογαριασμοί, κλειδιά API ή συνδρομή.

## 1. Τι περιλαμβάνει το αποθετήριο

- `app.js`, `server.js`: δημιουργία εφαρμογής και εκκίνηση server.
- `models/`: απλά αντικείμενα Player, Game, Grid, Challenge και αρχικά δεδομένα.
- `services/gameService.js`: κανόνες παιχνιδιού, ουρά, χρόνοι, ιδιοκτησία και σειρές.
- `routes/`: διαδρομές ανά πόρο, όλες καταχωρισμένες στο `routes/index.js`.
- `controllers/`: κοινός controller που αναμένει την εκτέλεση της αντίστοιχης λειτουργίας.
- `middleware/`: έλεγχοι εισόδου, καταγραφή αιτημάτων, κεντρικός χειρισμός σφαλμάτων.
- `config/`, `utils/`: σταθερές, ανάγνωση προδιαγραφής και κοινές βοηθητικές λειτουργίες.
- `docs/`: `swagger.json` (OpenAPI), `stories.json`, `requirements.json`, `SCOPE.md` (αποφάσεις scope) και `backend-prompt.md` (το prompt υλοποίησης).
- `test/`: αυτοματοποιημένοι έλεγχοι μέσω πραγματικού τοπικού HTTP server.
- `examples/`: έτοιμα JSON για τις εντολές curl.
- `API-REFERENCE.md`: όλες οι διαδρομές, σώματα αιτημάτων και βασικές απαντήσεις.
- `IMPLEMENTATION.md`: πλάνο, σταδιακή ανάπτυξη, τεχνικές αποφάσεις και όρια.
- `REQUIREMENTS.md`: αντιστοίχιση απαιτήσεων με λειτουργίες και δοκιμές.
- `TEST-RESULTS.md`: τι ελέγχθηκε στον τελικό κώδικα.
- `package-lock.json`: κλειδωμένες εκδόσεις για επαναλήψιμη εγκατάσταση.

Το αποθετήριο αφορά **το backend**. Δεν περιλαμβάνει React frontend, ήχους ή οθόνες παιχνιδιού.

## 2. Απαραίτητο πρόγραμμα

Node.js **22.19.0 ή νεότερο**, με npm. Ο έλεγχος έγινε με Node.js 24.22.3.
Σε υπολογιστή χωρίς Node, κατέβασε τον εγκαταστάτη από το [nodejs.org](https://nodejs.org/).
Μετά την εγκατάσταση άνοιξε ξανά το τερματικό και έλεγξε:

```text
node --version
npm --version
```

Απαιτείται σύνδεση Internet για την πρώτη λήψη των δωρεάν πακέτων npm.
Το παιχνίδι δεν καλεί εξωτερικές υπηρεσίες. Τα αρχικά avatar είναι URL εικόνων·
η εμφάνισή τους από frontend χρειάζεται πρόσβαση στον αντίστοιχο ιστότοπο.

## 3. Εγκατάσταση και εκκίνηση

1. Κάνε clone το αποθετήριο (ή άνοιξε τον τοπικό φάκελο του έργου).
2. Άνοιξε τερματικό **μέσα στον φάκελο `degrid-backend`**, εκεί όπου υπάρχει το `package.json`.
3. Εκτέλεσε:

```text
npm install
npm start
```

Για εγκατάσταση αυστηρά από το lockfile μπορείς να χρησιμοποιήσεις `npm ci` αντί `npm install`.
Ο server εμφανίζει:

```text
Degrid listening on http://127.0.0.1:3000; docs: /api-docs
```

Άνοιξε [http://127.0.0.1:3000/api-docs/](http://127.0.0.1:3000/api-docs/).
Εκεί υπάρχουν και οι 26 λειτουργίες με **Try it out → Execute**.
Το τερματικό πρέπει να παραμένει ανοιχτό. Διακοπή: **Ctrl+C**.

Για επιβεβαίωση χωρίς αλλαγή δεδομένων άνοιξε
[http://127.0.0.1:3000/games](http://127.0.0.1:3000/games).
Η ρίζα `/` δεν είναι ιστοσελίδα παιχνιδιού και επιστρέφει 404.

## 4. Η πιο εύκολη ολοκληρωμένη επίδειξη

Άφησε το `npm start` να τρέχει. Άνοιξε δεύτερο τερματικό στον ίδιο φάκελο:

```text
npm run demo
```

Η επίδειξη δημιουργεί νέο παιχνίδι με τέσσερις παίκτες, ζητά το κελί (2,2),
παίρνει την ερώτηση, στέλνει τη γνωστή απάντηση του demo και ελέγχει ότι:

- το κελί ανήκει πλέον στον παίκτη,
- ο παίκτης έχει δύο κελιά στην κατάταξη,
- η σειρά έχει περάσει στον επόμενο παίκτη.

Μπορεί να επαναληφθεί: κάθε εκτέλεση δημιουργεί καινούριο παιχνίδι.
Τελευταία γραμμή επιτυχίας: `Demo passed: acquisition, leaderboard and next turn agree.`

## 5. Χειροκίνητη δοκιμή με curl

Τα JSON δίνονται από αρχεία για να αποφεύγονται λάθη με εισαγωγικά.

Για το παρακάτω ακριβές παράδειγμα κάνε **νέα εκκίνηση του server** και μην τρέξεις
πρώτα το demo. Ολοκλήρωσε την απάντηση μέσα σε 40 δευτερόλεπτα από την επιλογή κελιού.
Ο παίκτης 1 ξεκινά τη σειρά του και το πρώτο challenge έχει ID 1.

```text
curl http://127.0.0.1:3000/games
curl http://127.0.0.1:3000/games/1/turn
curl -X POST http://127.0.0.1:3000/games/1/players/1/validate-input -H "Content-Type: application/json" --data-binary "@examples/coordinates.json"
curl "http://127.0.0.1:3000/games/1/challenges/1?playerId=1"
curl -X POST http://127.0.0.1:3000/games/1/players/1/challenge-answer -H "Content-Type: application/json" --data-binary "@examples/answer.json"
curl http://127.0.0.1:3000/games/1/players
curl http://127.0.0.1:3000/games/1/turn
```

Αναμενόμενο αποτέλεσμα απάντησης:

```json
{
  "success": true,
  "data": {
    "correct": true,
    "cellAcquired": true,
    "cell": {"cellId":18,"row":2,"column":2,"owner":1,"cellColour":3635792}
  },
  "error": null,
  "message": "Challenge passed; cell acquired."
}
```

Το GET της ερώτησης περιέχει μόνο `challengeId`, `question`, `options`, `timeLimit`.
Δεν περιέχει τη σωστή απάντηση. Οι γνωστές απαντήσεις του demo υπάρχουν στον κώδικα
των mock δεδομένων/δοκιμών, όπως αναμένεται για παραδιδόμενο mock backend.

Για δημιουργία νέου παιχνιδιού ή προσθήκη παίκτη στην ουρά:

```text
curl -X POST http://127.0.0.1:3000/games -H "Content-Type: application/json" --data-binary "@examples/create-game.json"
curl -X POST http://127.0.0.1:3000/queue/players -H "Content-Type: application/json" --data-binary "@examples/queue.json"
```

Για αλλαγή προφίλ, το Swagger απαιτεί **multipart/form-data**, όχι JSON:

```text
curl -X PUT http://127.0.0.1:3000/games/1/players/1/profile -F "username=PlayerOne" -F "language=el"
```

Προαιρετική εικόνα: πρόσθεσε `-F "avatar=@/path/to/avatar.png"` με πραγματική διαδρομή.
Γίνονται δεκτά PNG/JPEG/GIF/WebP έως 1 MiB. Η εικόνα μένει στη μνήμη ως data URL.

## 6. Αρχικά δεδομένα και χρόνοι

Σε κάθε εκκίνηση υπάρχουν 48 mock παίκτες με IDs 1–48, ένα ενεργό παιχνίδι με
τους 1–4 και ουρά με τους 5–6. Οι υπόλοιποι είναι διαθέσιμοι. Κάθε παίκτης του
παιχνιδιού αρχίζει με ένα διαφορετικό κελί στην περίμετρο. Το grid έχει 256 κελιά.
Οι ερωτήσεις επιλέγονται κυκλικά από τέσσερα mock θέματα και κάθε προσπάθεια
παίρνει μοναδικό ID, δεμένο στον παίκτη και στο παιχνίδι.

- Συντεταγμένες: **1–16**, όπως στα mockups. `cellId = (row - 1) × 16 + column`.
- Κεντρικά κελιά: (8,8), (8,9), (9,8), (9,9). Ένας κοινός ιδιοκτήτης ολοκληρώνει το παιχνίδι.
- Σειρά επιλογής: 60 δευτερόλεπτα. Ερώτηση: 40 δευτερόλεπτα από την επιλογή κελιού.
- Επαναλαμβανόμενο GET ή ίδια επιλογή δεν ανανεώνει τον χρόνο της ερώτησης.
- Σωστή απάντηση, λάθος απάντηση ή λήξη ερώτησης προχωρούν τη σειρά μία φορά.
- Αδράνεια: 300 δευτερόλεπτα. Αιτήματα με συγκεκριμένο παίκτη ανανεώνουν τη δραστηριότητά του.
  Το frontend μπορεί να καλεί το δικό του `GET /games/{gameId}/players/{playerId}` ανά 30–60 δευτερόλεπτα.
  Η γενική ανάγνωση του grid δεν λειτουργεί ως heartbeat όλων των παικτών.
- Η ουρά δημιουργεί αυτόματα παιχνίδι μόλις βρεθούν τουλάχιστον τέσσερις παίκτες,
  έως 36 ανά παιχνίδι. Μικρότερο υπόλοιπο παραμένει στην ουρά.
- Με λιγότερους από τέσσερις παίκτες, στα 360 δευτερόλεπτα το μήνυμα ζητά αναμονή
  και το χρονόμετρο της ουράς ξεκινά ξανά.
- Η αποχώρηση καθαρίζει τα κελιά και τη σειρά του παίκτη. Κάτω από δύο εναπομείναντες
  παίκτες το ενεργό παιχνίδι ολοκληρώνεται.
- Rematch: μόνο μετά το τέλος, με τουλάχιστον τέσσερις συνδεδεμένους συμμετέχοντες
  και ομόφωνη θετική ψήφο. Το ίδιο gameId ξεκινά ξανά με καθαρό grid.

**Με διακοπή/επανεκκίνηση χάνονται όλες οι αλλαγές.** Αυτό είναι απαιτούμενη συμπεριφορά,
όχι σφάλμα αποθήκευσης.

## 7. Ρυθμίσεις και React

Το `.env` είναι προαιρετικό. Αν χρειάζεται, αντίγραψε το `.env.example` σε `.env` (`cp .env.example .env`).

| Ρύθμιση | Προεπιλογή | Χρήση |
|---|---:|---|
| PORT | 3000 | Θύρα server |
| HOST | 127.0.0.1 | Τοπική διεύθυνση ακρόασης |
| INACTIVITY_SECONDS | 300 | Όριο αδράνειας |
| TURN_SECONDS | 60 | Χρόνος επιλογής πριν από challenge |
| CHALLENGE_SECONDS | 40 | Χρόνος απάντησης στην ερώτηση (challenge) |
| LOG_REQUESTS | true | Καταγραφή μεθόδου, διαδρομής, status και διάρκειας |

Για άνετη χειροκίνητη παρουσίαση μπορείς να αυξήσεις `TURN_SECONDS=600` και
`INACTIVITY_SECONDS=1800` και να επανεκκινήσεις. Το όριο ερώτησης είναι 40 δευτερόλεπτα και αλλάζει με το `CHALLENGE_SECONDS`.

Το React χρησιμοποιεί βάση `http://127.0.0.1:3000`, χωρίς πρόσθετο `/api`.
Το CORS επιτρέπει όλες τις προελεύσεις. Δεν υπάρχει authentication, σύμφωνα με το prompt.
Η απάντηση έχει πάντα `{success, data, error, message}`. Σφάλματα εισόδου: 400,
ανύπαρκτοι πόροι: 404, οι ορισμένες συγκρούσεις: 409, απρόβλεπτα σφάλματα: 500.
Μηνύματα, popup και ήχοι προβάλλονται/παίζονται από το frontend με βάση τις απαντήσεις.

## 8. Έλεγχοι

Δεν απαιτείται να τρέχει ο server για τα παρακάτω. Οι δοκιμές ανοίγουν προσωρινούς
τοπικούς servers σε ελεύθερες θύρες και τους κλείνουν αυτόματα.

```text
npm run check:spec
npm run check:code
npm test
```

Το `check:spec` επικυρώνει το πλήρες OpenAPI και την ακριβή αντιστοίχιση 26 διαδρομών.
Το `check:code` ελέγχει σύνταξη ES modules και παρουσία σχολίων JSDoc στις συναρτήσεις.
Το `npm test` ελέγχει πραγματικά HTTP αιτήματα, σχήματα απαντήσεων και βασικές ροές.
Η αναλυτική κάλυψη και τα αποτελέσματα βρίσκονται στο `TEST-RESULTS.md`.

## 9. Σημεία που χρειάζεται να γνωρίζει η ομάδα

Οι αποφάσεις scope (οθόνες, οντότητες, αλλαγές στο Swagger) βρίσκονται στο docs/SCOPE.md. Οι αποφάσεις υλοποίησης για μη ορισμένες λεπτομέρειες βρίσκονται στο IMPLEMENTATION.md.

Το `inputcoordinates` στο τελικό Swagger αφορά **αξιολόγηση ή εκτέλεση ανταλλαγής**
και επιστρέφει Cell. Εδώ αξιολογεί κελί άλλου παίκτη χωρίς αλλαγή ιδιοκτησίας.
Δεν δίνονται προσφερόμενο κελί, αποδοχή αντισυμβαλλομένου ή κανόνας ανταλλαγής,
οπότε δεν προστέθηκε αυθαίρετη αναγκαστική ανταλλαγή. Για κατάκτηση ελεύθερου κελιού
χρησιμοποιούνται `validate-input` ή το PUT επιλογής κελιού και κατόπιν challenge-answer.

Τα system endpoints επεξεργασίας grid/cell είναι διαθέσιμα ακριβώς όπως ζητούνται,
χωρίς authentication. Η ομάδα του frontend πρέπει να τα χρησιμοποιεί ως λειτουργίες
συστήματος. Το πακέτο είναι εκπαιδευτικό mock backend για τοπική εκτέλεση.

## 10. Συνήθη προβλήματα

| Πρόβλημα | Ενέργεια |
|---|---|
| `npm` δεν αναγνωρίζεται | Εγκατάστησε Node.js με npm και άνοιξε νέο τερματικό. |
| Δεν βρίσκεται `package.json` | Άνοιξε τερματικό στον φάκελο `degrid-backend`. |
| `EADDRINUSE` | Κλείσε προηγούμενο server ή άλλαξε PORT στο `.env`. |
| `It is another player's turn` | Δες `/games/1/turn`. Για το αρχικό παράδειγμα επανεκκίνησε ή τρέξε `npm run demo`. |
| Παίκτης δεν βρίσκεται μετά από αρκετά λεπτά | Αφαιρέθηκε λόγω αδράνειας. Επανεκκίνησε για αρχικά δεδομένα. |
| Λάθος Content-Type στο profile | Χρησιμοποίησε multipart/form-data με `-F`, όχι JSON. |
| Δεν εμφανίζεται παιχνίδι στον browser | Αυτό είναι backend. Χρησιμοποίησε `/api-docs/` ή σύνδεσε το React frontend. |

Αν αλλάξεις PORT, το demo μπορεί να πάρει άλλη βάση από `BASE_URL` (π.χ. `BASE_URL=http://127.0.0.1:3001 npm run demo`)
